# docs/runbooks/

Operational runbooks for setup, module recovery, and demo preparation.

Each runbook is a step-by-step guide that a developer can follow without needing to understand the full codebase.

## Runbooks to be added (G5–G6)

| File | Owner | Purpose |
|---|---|---|
| `setup.md` | Dev1 | Clean clone → first run on a new machine |
| `reset.md` | Dev1 | Full database reset with seed reload |
| `backup-restore.md` | Dev1 | Database backup and restore procedures |
| `offline-start.md` | Dev1 | Start the system with no internet access |
| `demo-checklist.md` | Dev5 | Pre-demo verification and golden journey walkthrough |
| `module-a-recovery.md` | Dev2 | Staff / auth module troubleshooting |
| `module-b-recovery.md` | Dev3 | Patient / insurance module troubleshooting |
| `module-c-recovery.md` | Dev1 | Scheduling module troubleshooting |
| `module-d-recovery.md` | Dev4 | Clinical / billing / payment troubleshooting |
| `module-e-recovery.md` | Dev5 | Reports / import troubleshooting |

> Runbooks are written as part of **Gate G5** (CATMS-077, CATMS-078, CATMS-080).
